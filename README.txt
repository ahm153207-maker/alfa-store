# ALFA — Essentials 001

A responsive starter storefront for the ALFA clothing brand.

## Run locally
1. Unzip this folder.
2. Open the `ALFA_Online_Store` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Publish as a public link (Netlify Drop)
1. Visit https://app.netlify.com/drop
2. Sign in / create a free Netlify account.
3. Drag the unzipped `ALFA_Online_Store` folder onto the drop area.
4. Netlify will publish it and give you a public website URL.

## Easy edits
- Product names, prices, colors, and image URLs are in `script.js` inside the `catalog` array.
- Main page content is in `index.html`.
- Styling is in `style.css`.

## Important
This is a front-end prototype. The WhatsApp order button opens a prefilled message, but it does not collect customer details or store orders. Replace demo images and prices with approved product assets and prices. The size guide is a placeholder; confirm actual garment measurements from samples before selling.
